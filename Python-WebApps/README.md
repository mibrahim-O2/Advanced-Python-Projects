## 🧠 Python Quiz Web App

A web-based **Python Quiz Application** built with Flask that allows users to test their Python knowledge through multiple-choice questions in a timed environment.

### ✨ Highlights
- 50 Python MCQ questions  
- 60-minute countdown timer  
- Previous / Next navigation  
- Auto-submit on time completion  
- Score, percentage & performance feedback  

### 🛠 Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Bootstrap 5
