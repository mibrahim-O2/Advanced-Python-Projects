## 01 Python Quiz Web App

A web-based **Python Quiz Application** built with Flask that allows users to test their Python knowledge through multiple-choice questions in a timed environment.

###  Highlights
- 50 Python MCQ questions  
- 60-minute countdown timer  
- Previous / Next navigation  
- Auto-submit on time completion  
- Score, percentage & performance feedback  

###  Tech Stack
- Python (Flask)
- HTML, CSS, JavaScript
- Bootstrap 5

## 02 Face Recognition Web App

A **real-time face recognition web app** built with **Python, Flask, OpenCV, and MediaPipe**. This project demonstrates how to capture webcam video, detect faces, and display the live stream on a web interface.

**Skills Learned:**
- Python programming and modular code structure
- Real-time computer vision with OpenCV and MediaPipe
- Web development with Flask (templates, routing, video streaming)
- Frontend-backend integration for interactive apps
- Project organization and version control with Git/GitHub
