# Face Recognition Web App

A **Python web application** for real-time face detection and recognition using a webcam. This project demonstrates how to build a full-stack computer vision web app with practical tools and technologies.  

It’s ideal for learning **Python, Flask, OpenCV, MediaPipe, and basic web development** while applying them in a real-world project.

---

## Skills You Will Learn

By studying or building this project, you will gain practical experience in:

### 1. Python Programming
- Working with **classes and functions** to structure code (`Camera.py`, `app.py`).  
- Handling **images and arrays** using **Pillow (PIL)** and **NumPy**.  
- Reading and writing files, including organizing known-face images.

### 2. Computer Vision
- Capturing live video streams with **OpenCV**.  
- Detecting faces in real-time using **MediaPipe Face Detection**.  
- Drawing bounding boxes and annotations on images and frames.  
- Preprocessing images for face recognition (resizing, RGB conversion, handling RGBA).

### 3. Web Development with Flask
- Creating a **Flask server** to serve a live video stream.  
- Using **Jinja2 templates** to dynamically display video frames in HTML.  
- Understanding HTTP streaming (`multipart/x-mixed-replace`) for live video.  
- Linking static assets and templates to Flask routes.

### 4. Integration of Frontend and Backend
- Serving a **real-time camera feed** to a web page.  
- Combining Python backend logic with HTML/CSS frontend for interactive apps.  
- Structuring a **full-stack project** with `static`, `templates`, and backend code.

### 5. Version Control & GitHub
- Organizing projects with **Git and GitHub**.  
- Managing commits, branching, and pushing updates to a remote repository.  
- Structuring nested folders in a repo for clean project organization.

### 6. Project Organization & Best Practices
- Separating logic into modules (`Camera.py` for video processing).  
- Maintaining a **folder for known faces** for scalable recognition.  
- Keeping templates and static files organized for maintainable web apps.

---

## Tools & Technologies Used

- **Python 3.10+** – Core programming language.  
- **Flask** – Web framework for serving the app.  
- **OpenCV** – Image/video capture and processing.  
- **MediaPipe** – Fast and reliable real-time face detection.  
- **NumPy** – Handling image arrays efficiently.  
- **Pillow (PIL)** – Loading and converting images.  
- **HTML/CSS** – Simple frontend to display live camera feed.  
- **Git & GitHub** – Version control and remote repository management.

---

## Key Learning Outcomes

After completing or studying this project, you will be able to:

- Build **real-time computer vision apps** with Python.  
- Stream video from Python to a browser using Flask.  
- Detect and recognize faces efficiently using MediaPipe.  
- Integrate backend Python code with frontend web interfaces.  
- Organize a project folder and manage version control with GitHub.  
- Understand the workflow for deploying small Python web apps.

This project is an excellent example for beginners or intermediate Python developers to **combine web development, computer vision, and practical coding skills** into a single functional application.
